## 1. 作品と仕様の要点（変わらない前提）

- 素材（cello 683 s、prism 386 s、scri 710 s、stringquartet 520 s）とゴール（`material_GOAL_001` 30 s）を固定ループで同時開始し、
  **音量だけ**（後に利用者が許可した範囲で再生位置ジャンプと出力ダイナミクスも）で
  `INTRO → OPEN → CONTRACT → GOAL_HOLD → REOPEN → …` の周期を作る。
- 四方式（diffusion / vae / transformer / gan）は「音響配合状態 ξ の理想・関係・可能性の法則」を定義する制御器で、
  ゲインは近似実現の手段。理想への完全一致は不要だが、音量のみ・厳密ゴール・履歴の使用・四方式の異なる計算は必須。
- 配合状態 ξ = [φ̃（対数エネルギー、帯域比率、flux）| 寄与 c（M 本）| 素材ペア関係 upper(R)]。距離 d_ξ² は式(22)。
- ゴール保持区間は `g = e_0` を定数として厳密保持し、生レンダリングが `B·x_0` と一致することを検証する。
- 基準レベル `B = min(1, 0.85 / Σ peak_i)` = 0.214（実素材）。従来版の出力ピークは約 −15 dBFS。
- 状態ラベル：`VALID_APPROXIMATION` / `BEST_EFFORT`（正常出力）/ `HARD_CONSTRAINT_FAILURE` / `INCOMPLETE_IMPLEMENTATION` / `INPUT_ERROR` / `INTERNAL_ERROR`。
  `calibration_status` / `perceptual_status` は常に `UNVERIFIED`。

仕様の原本は利用者が会話で渡した v1.1（H5）。監査側の v1.1 はキー名・式番号が異なる別版で、設定キーの別名変換で吸収している
（`schedule.*`→`form.*`、`motion.relative_rate_max` など。未知キーはエラー）。

## 4. 実現層の現状（三つの経路が共存、すべて設定で切替）

1. **従来版**（`hires.enabled=false`）：Bank の暖機解 → 1.5 s ごとに窓参照（10 s）を凍結 → Bump 補正の座標探索 → 確定 → 履歴 ρ(Δt)。
   運動制約（V 0.12/s、A 0.08、J 0.12、相対 dB 12、最小移動 0.02、低速規則）を全面適用。
2. **高精細 v1**（`hires.enabled=true`, `fragment_vocabulary=false`）：0.5 s 確定、0.25 s ランプ（低速規則は利用者許可で放棄）、
   単一トラックの位置ジャンプ（46 ms 特徴で候補選択）、マスター段。
3. **断片語彙版**（`hires.enabled=true`, `fragment_vocabulary=true`）：候補は 2 秒平均の断片特徴、複数トラック同時ジャンプの
   ビーム探索（幅 3、8 行の部分集合で厳密混合評価）、24 帯域（d_ξ=41）、方式内部時間 0.5 s、方式の理想を断片配合の上で生成。

共通：参照は窓ごとに凍結（hash 記録、`reference_updated_during_realization=false`）、改善は音量／位置側のみ、確定ブロックは履歴と
方式の `observe_committed` へ。ゴールは連続時計のまま、CONTRACT 末尾 12 s で Q5 上昇、GOAL_HOLD で厳密 1、REOPEN で Q5 下降。
`mode.update()` は呼ばれない（監査 B5 の禁止事項）。

## 5. 四方式の現状設計（断片語彙版）

- **Diffusion**：配合場 𝓔_D（アンカー項＋ペア項＋三者項＋ridge＋ゴール項、係数 w/s/d/β は確定履歴の h_c, M_H, corr, change_direction から）。
  断片モードでは SDE を音楽時間で積分（model_step 0.5 s、drift サブステップ 10、信頼領域）、アンカーは断片配合 24 本×3 オフセットの平均、
  `frag_step=40`, `frag_temperature_per_openness=0.0016`。window_error = 平均 d_ξ² ＋ κ_E·場エネルギー。relation_terms 供給。
  統計：確定配合の場エネルギー 0.29 vs ランダム断片 0.73。
- **VAE**：基底は断片配合 300×5 行の SVD（W^{1/2} 尺度、k=4 実素材／3 fixture、符号規則、ジョブ内固定、mode_state に保存）、
  デコーダ ξ_G + Σ s_k tanh(z_k) v_k（s_k は 99 パーセンタイル則）、潜在 OU（相関 0.949 s）を model_step の節点で描き行へ補間、
  Σ_H 床 0.09。統計：飽和 0.04%、未使用 30%。
- **Transformer**：断片トークン（素材ごと 6 断片＋ゴール）、値は断片を前景化した厳密配合との差、類似／対照／記憶ヘッド、
  記憶は確定イベント（src_position 付き）＋長期ダイジェスト、AR は model_step で実現済み現在から、放射状有界化（使用率 0.000）、
  dt_scale 0.5（`fragment_step_seconds_reference` = 2×model_step）。統計：注意エントロピー、再帰率。
- **GAN**：参照分布＝断片配合のランダム軌道（12 本、2 s ブロック、ゴール露出方針に従う）、親＝確定配合経路＋新規参照、
  基底 SVD、生成 p_Θ(b,w)、識別器（同一行、標準化は最初のユニットで固定）、D/G 更新は各確定観測で（重要度補正・ESS）、
  基底変更時に μ/log σ 再初期化。統計：D 確定 0.27 vs ランダム断片 0.54。

各方式のローカル設定キーはすべて `config.py` の DEFAULTS に登録済み（未知キーは拒否されるため）。

## 7. 正直な留保（次セッションで誤解しないために）

- 「方式の潜在空間に近づいた」は、固定参照残差と 0.5 s 単位の統計（場エネルギー、D 値、有界化使用率、tanh 使用率）で示している。
  0.1 s 単位の速い成分の相関は依然低く、素材の内部変化が支配する。

  （v1 の残差は従来版より悪化していた）。断片語彙版はその上で理想側を到達可能集合に合わせたもの。
- 周期スイープの差は数％で優位は弱い。GAN の第 1 区間は残差が大きい（参照が散る）。
- 運動上限・聴感の校正は未実施。高精細版は低速規則を放棄（利用者許可、trace に `waived` と記録）。

## 16. 追記：同時に鳴る素材数の上限（2026-09-17 午後。未コミット。§15 の内容も未コミットのまま）

利用者の判断：**素材は 8〜12 本、同時に重ねてよい素材は最大 3**（後から設定で変えられること）。数え方＝同じ素材の 2 声は 1 素材、
入れ替えの 0.25 秒クロスフェード中は一時的に 4〜6 素材になってよい、鳴っている最中のジャンプは可。

### 16.1 実装

- 設定（`hires`）：`max_active_materials`（0＝上限なし、fid 設定は 3）、`min_sounding_seconds`（鳴り始めた素材の最低発音時間、fid 設定は 2.0。

- エンジン（`hires.py`）：`project_levels`（音量上位 K 素材を残す。最低発音時間内の素材は外せない／無音化されたら直前の音量に戻す）を
  `plan_rows`・先読み・ヒント・実現器の音量探索に適用、実現器は入れ替え（1 素材を消し無音の 1 素材を入れる）を試す。`HiresState.entered_at`。
  方式へ `realizer_state["max_active_materials" / "material_of_track" / "project_levels" / "min_sounding_frames" / "entered_at"]`。
  `Analyzer.cap_random_levels`（ランダムな合法状態＝1〜K 素材が鳴る）と、それを使う `random_fragment_composition`。
- ハード検査 `hard_checks.polyphony_cap`：50 ms 格子でランプ外の同時発音素材数、最短発音区間、発音数ごとの時間割合。smoke に素材 7 本・上限 3 の検査。
- 四方式（4 エージェント並列、契約は `docs/FIDELITY_CONTRACT.md` 末尾）：diffusion＝連鎖の状態を合法状態にし、音量移動は鳴っている素材だけ、

  ガード（上限の有無によらず適用するよう本セッションで変更）。上限 0 のときは各方式とも従来と同一動作（fixture でビット一致を確認）。
